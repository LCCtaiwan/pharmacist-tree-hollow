# Product Plan: 藥師樹洞

## Product Choice

建議第一版做 Web App MVP，不先做純 LINE Bot 或完整遊戲。

理由：

- 你回來驗收時，Web App 最能展示完整體驗與視覺療癒感。
- 樹洞、誇誇、今日療癒、點歌、抽牌、收藏、小樹成長可以放在同一個可操作介面。
- 不需要先申請 LINE Channel 就能開始開發。
- 核心 AI、安全與內容模組之後可以重用到 LINE Bot。

LINE Bot 可放在第二階段，作為藥師日常短入口。遊戲化可放在 Web App 內，以小樹成長、療癒牌和視覺 token 呈現，但不要讓使用者有打卡壓力。

## Positioning

一句話：

```text
給藥師下班前、崩潰後、撐住時，用 30 秒被理解一下的 LINE 樹洞。
```

核心價值：

- 被聽見。
- 被具體稱讚。
- 得到一個很小、做得到的下一步。
- 用療癒內容轉換心情。

## MVP Feature Priority

### P0

- 樹洞傾聽：輸入壓力事件，回覆同理、誇誇、小步驟。
- 誇誇我：根據藥師情境產生具體稱讚。
- 危機安全流程：自傷/傷人/極端危機導向求助。
- 醫療與個資邊界：避免處方建議與病人個資保存。

### P1

- 今日療癒：自寫金句、公共領域短句或授權短摘。
- 心情點歌：依心情推薦歌曲，不提供歌詞。
- 娛樂型抽牌：塔羅或藥師療癒牌。
- 喘口氣：30 秒呼吸或 grounding。

### P2

- Web PWA 心情日記。
- 收藏回覆與金句。
- 後台內容庫。
- 匿名週報。

### P3

- 自創牌組插圖。
- 小樹成長或低壓遊戲化。
- Spotify/YouTube Music 深連結。
- 多語系。

## Main Conversation Flows

### 樹洞

```text
User: 今天又被客人罵，還要一直趕處方，真的很煩。
Bot:
聽起來你今天被情緒和工作量兩邊夾住了。
你還能把處方流程撐住，這不是普通的耐力，是專業在硬撐。
現在先喝一口水，讓肩膀放下來 10 秒就好。
[誇誇我] [幫我點歌] [抽一張牌]
```

### 誇誇我

```text
Bot:
今天的你值得被記一筆：在混亂裡還有確認、還有交代、還有把關。
你不是只有「完成工作」，你是在替很多人守住安全。
```

### 點歌

```text
Bot:
今天適合：〈給自己的歌〉李宗盛
理由：它不是硬叫你振作，而是陪你承認「有些累是真的」。
```

### 抽牌

```text
Bot:
這是娛樂型抽牌，用來整理心情，不是預測或專業建議。
你抽到：節制
今天的提示：你不需要一次把所有人的期待都接住。先把自己的節奏拿回來。
反思問題：現在有哪一件事可以先做到 70 分就好？
```

## Tone Guide

要做：

- 具體。
- 短。
- 像懂藥師工作的人。
- 承認壓力，不急著正能量。

避免：

- 「你要加油」這種空泛句。
- 診斷語氣。
- 道德勸說。
- 叫使用者忍耐或責怪自己。
- 長篇大道理。

## Content Strategy

內容類型：

- 自寫療癒句：最安全，可大量使用。
- 公共領域短句：需保留來源。
- 現代書摘：只做短摘或改寫心得，避免大量引用。
- 歌曲推薦：只列歌名、歌手、推薦理由，不提供歌詞。
- 塔羅牌義：建立自己的牌義資料表，避免複製受版權內容。

## Pilot Metrics

- 完成一次互動率。
- 使用者是否點第二個 quick reply。
- 「有被理解」評分。
- 「有藥師感」評分。
- 危機流程觸發與人工複查數。
- 被標記為不舒服、不準確或太雞湯的回覆比例。

## Recommended Next Step

先實作 Web App MVP，不接資料庫也可以。用固定測試案例驗證語氣、安全與互動節奏，再決定是否接 AI provider、LINE Bot 與更完整的遊戲化場景。
