# 樹洞 AI 切片 A：API endpoint scaffolding 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 加一個 Vercel Serverless Function `/api/respond`，接受 `{input, mood}` 紙條後呼叫 Gemini 2.5 Flash，回傳符合四 mode schema 的 JSON。前端尚不串接，只用 curl 驗證。

**Architecture:** Vercel `/api/respond.ts` 為 thin entry，邏輯模組化到 `/api/_lib/` 底下（system prompt、Gemini client、schema validator）。前端在切片 B 才接。

**Tech Stack:** Vercel Functions (Node 22 runtime) · TypeScript · `@google/genai` SDK · Vitest（單元測試）· vercel CLI（本地測）

`api/_lib/schema.ts`：

```ts
export type AILetterMode = "hold_and_praise" | "praise_only" | "hold_only" | "crisis";

export interface AILetterResponse {
  mode: AILetterMode;
  careTitle: string;
  hold: string;
  praise: string;
  praiseNotes: string[];
}

const VALID_MODES: readonly AILetterMode[] = [
  "hold_and_praise",
  "praise_only",
  "hold_only",
  "crisis"
];

const MAX_CARE_TITLE_LEN = 14;

export function validateAILetter(input: unknown): AILetterResponse {
  if (typeof input !== "object" || input === null) {
    throw new Error("input must be an object");
  }
  const obj = input as Record<string, unknown>;

  if (typeof obj.mode !== "string" || !VALID_MODES.includes(obj.mode as AILetterMode)) {
    throw new Error(`invalid mode: ${String(obj.mode)}`);
  }
  if (typeof obj.careTitle !== "string") {
    throw new Error("missing careTitle (must be string)");
  }
  if ([...obj.careTitle].length > MAX_CARE_TITLE_LEN) {
    throw new Error(`careTitle too long (${[...obj.careTitle].length} > ${MAX_CARE_TITLE_LEN})`);
  }
  if (typeof obj.hold !== "string") {
    throw new Error("missing hold (must be string)");
  }
  if (typeof obj.praise !== "string") {
    throw new Error("missing praise (must be string)");
  }
  if (!Array.isArray(obj.praiseNotes)) {
    throw new Error("missing praiseNotes (must be array)");
  }
  if (!obj.praiseNotes.every((n) => typeof n === "string")) {
    throw new Error("praiseNotes must be array of strings");
  }

  return {
    mode: obj.mode as AILetterMode,
    careTitle: obj.careTitle,
    hold: obj.hold,
    praise: obj.praise,
    praiseNotes: obj.praiseNotes as string[]
  };
}
```

```ts
不要空泛稱讚。

1. hold_and_praise
條件：紙條有負面情緒、疲憊、委屈、懊悔、壓力，且能從文字中看出使用者做了某個具體動作。

2. praise_only
條件：紙條偏中性、報告式、小確幸、完成一件事，沒有明顯情緒需要先接住。

4. crisis
條件：出現自傷、求死、想消失、不想活、活著很累、沒有明天、交代後事、可能傷害自己或他人、立即危險、極端絕望，或語意接近上述情況。
危機判斷寧可往上報。
只給最短接住，不給誇誇。
前端會接專業資源與 1925 / 1995 / 1980。

# 灰色地帶判斷

- 有負面情緒 + 有具體行動：選 hold_and_praise。
- 有負面情緒 + 沒有可誇的具體行動：選 hold_only。
- 內容太重，誇誇可能像美化痛苦：選 hold_only。

- 使用者只是問問題，且不是情緒紙條：用 hold_only，簡短設界線。

2. 不使用第一人稱「我」。

   - 你必須
   - 你要記得

   - 你很棒

- 8 到 12 個中文字為佳
```

```ts
import { GoogleGenAI } from "@google/genai";
import { SYSTEM_PROMPT } from "./system-prompt";
import { validateAILetter, type AILetterResponse } from "./schema";

const MODEL = "gemini-2.5-flash";

const responseSchema = {
  type: "object",
  required: ["mode", "careTitle", "hold", "praise", "praiseNotes"],
  properties: {
    mode: {
      type: "string",
      enum: ["hold_and_praise", "praise_only", "hold_only", "crisis"]
    },
    careTitle: { type: "string", maxLength: 14 },
    hold: { type: "string" },
    praise: { type: "string" },
    praiseNotes: {
      type: "array",
      items: { type: "string" },
      maxItems: 3
    }
  }
} as const;

export async function callGemini(input: string, mood: string): Promise<AILetterResponse> {
  const apiKey = process.env.GEMINI_API_KEY;
  if (!apiKey) {
    throw new Error("GEMINI_API_KEY not set in environment");
  }

  const client = new GoogleGenAI({ apiKey });

  const userMessage = `紙條：${input}\n\n當前心情標籤：${mood}`;

  const result = await client.models.generateContent({
    model: MODEL,
    contents: [{ role: "user", parts: [{ text: userMessage }] }],
    config: {
      systemInstruction: SYSTEM_PROMPT,
      responseMimeType: "application/json",
      responseSchema,
      temperature: 0.8,
      maxOutputTokens: 800
    }
  });

  const text = result.text ?? "";
  let parsed: unknown;
  try {
    parsed = JSON.parse(text);
  } catch (err) {
    throw new Error(`failed to parse Gemini JSON: ${text.slice(0, 200)}`);
  }

  return validateAILetter(parsed);
}
```

## Task 5：建立 `/api/respond.ts` handler

**Files:**
- Create: `api/respond.ts`

- [ ] **Step 5.1：實作 handler**

```ts
import type { VercelRequest, VercelResponse } from "@vercel/node";
import { callGemini } from "./_lib/gemini-client";

const MAX_INPUT_LEN = 500;
const VALID_MOODS = ["累", "煩", "委屈", "想哭", "空", "緊繃", "還可以"];

export default async function handler(
  req: VercelRequest,
  res: VercelResponse
): Promise<void> {
  if (req.method !== "POST") {
    res.status(405).json({ error: "method_not_allowed" });
    return;
  }

  const body = req.body as { input?: unknown; mood?: unknown } | undefined;
  if (!body || typeof body !== "object") {
    res.status(400).json({ error: "invalid_body" });
    return;
  }

  const { input, mood } = body;
  if (typeof input !== "string" || input.trim().length === 0) {
    res.status(400).json({ error: "missing_input" });
    return;
  }
  if (typeof mood !== "string" || !VALID_MOODS.includes(mood)) {
    res.status(400).json({ error: "invalid_mood" });
    return;
  }

  const truncated = input.slice(0, MAX_INPUT_LEN);

  try {
    const letter = await callGemini(truncated, mood);
    res.status(200).json({ ...letter, source: "ai" });
  } catch (err) {
    console.error("[/api/respond] error:", err instanceof Error ? err.message : err);
    res.status(502).json({ error: "ai_failed" });
  }
}
```

## 預期障礙與緩解

| 障礙 | 症狀 | 緩解 |
|---|---|---|
| @google/genai SDK 版本變動 | API 介面不同（例如 `.models.generateContent` 被改） | pin 一個確定能用的版本、看 https://github.com/googleapis/js-genai 最新 changelog |
| Vercel function 預設 10s timeout | Gemini 偶爾慢 | hobby tier 已是 10s 上限、Gemini Flash 1-2s 應該夠；若超時加 retry/fallback（切片 B 處理） |
| Gemini 偶發 4xx/5xx | API key 限額、地區限制 | check console error、確認 free tier 還有 quota |
| responseSchema 不被遵守 | 回的 JSON 缺欄位 | validator 會擋住、return 502；Gemini 2.5 Flash 通常很穩 |
| 中文 length 算錯（chars vs bytes） | careTitle 過長被誤判 | 用 `[...str].length` 算 codepoint 數，避免 surrogate pair 出錯（已寫在 validator） |
| 本地 vercel dev 無法 hot reload api/ | 改 api/ code 後沒生效 | 重啟 `vercel dev` 或用 `--debug` |
| Vercel monorepo 不識別 /api/ | function 路由 404 | 在 vercel.json 明確設 `functions` 或把 api/ 放對位置；本計畫放 repo root 是 vercel 標準 |
| api/ TypeScript 報 `@vercel/node` 找不到 | Type 缺失 | 確認 `npm install --save-dev @vercel/node` 已執行 |
| 月預算炸 | Gemini 用量超出 | 切片 A 還沒 rate limit，curl 手動測完就停 vercel dev；切片 C 處理 rate limit |
