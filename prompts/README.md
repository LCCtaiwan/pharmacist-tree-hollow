# Prompts

Prompt specifications for AI-assisted responses.

## Planned Files

- `system.md`: Global assistant behavior.
- `vent.md`: 樹洞傾聽 response schema.
- `praise.md`: 誇誇 response schema.
- `song.md`: 心情點歌 response schema.
- `tarot.md`: 娛樂型抽牌 response schema.
- `safety.md`: Crisis and refusal templates.

## Rule

Prompts must be tested with safety cases before production use.
